# Formulários em HTML e CSS

Dois exercícios de formulário feitos no começo dos meus estudos de front-end.

| Pasta | O que é |
|---|---|
| `pagina-de-login/` | Tela de login com imagem de fundo e campos de usuário e senha |
| `cadastro-de-devs/` | Formulário de cadastro de pessoas desenvolvedoras |

Só a parte visual foi feita: os formulários não enviam dados para lugar nenhum.

## Como ver

Abra o `index.html` de cada pasta no navegador.
